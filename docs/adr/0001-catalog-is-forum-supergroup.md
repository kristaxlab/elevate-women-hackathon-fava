# Catalog lives in a forum-enabled Telegram supergroup

Fava’s Catalog is not a broadcast channel and not a DM-only archive. Telegram forum topics (Inbox, Smart Search, Theme Topics) only exist on forum-enabled **supergroups**, so each Catalog is exactly one such group with Fava as admin (including manage-topics). Channels were rejected because they cannot host forum topics; a pure DM library was rejected because it cannot show the “folder per theme” browsing model the product promises.
