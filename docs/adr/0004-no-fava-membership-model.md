# No Fava membership or invite model

The product is personal favorites save & search. Telegram already lets a Catalog Owner invite people to the group; Fava does not track joins, roles, per-user libraries inside a group, or invite onboarding. Anyone Telegram allows to post may use Inbox and Smart Search; only group admins may run Setup. Building team-workspace semantics would dilute the personal catalog pitch and add schema Fava does not need for the hackathon.
